# 佣金仪表盘（按月）

目标：打开就看「这个月，每个渠道该分多少钱，是哪几个客户带来的」。

**这张仪表盘没法用脚本建**（2026-09-18 实测）：多维表格的仪表盘接口只有「列出仪表盘」和
「复制仪表盘」两个，没有创建，组件（图表）的接口也不存在。所以下面的步骤要在界面上点一次。
**其余部分都能自动复刻**：列结构、公式、关联、导入都是脚本干的，换到生产的 Base 只需要
换 `.env` 再跑 `sync_base.py --apply` + `import_daily_board.py`。

## 数据来自哪几列

都在 `Daily Revenue Board` 上（列的定义见 [SCHEMA.md](SCHEMA.md)）：

| 列 | 来源 | 用在哪 |
| --- | --- | --- |
| 月份 | 公式 `TEXT(交易日期, "yyyy-MM")` | 按月筛选 / 分组 |
| 渠道编号、渠道名称 | 公式（沿「客户」关联反查） | 每个渠道一行 |
| 客户名称 | 导入的原始列 | 「哪几个客户带来的」 |
| 总收入(opt+现货+合约) | 导入的原始列 | 佣金基数 |
| 分佣比例 | 公式 | 渠道比例 |
| 本笔佣金 | 公式 | **要汇总的钱** |

## 步骤

打开 Base：**https://feishu.cn/base/Vul2bO30cahcGIspKIrchvxdnef**

1. 左侧导航栏悬停「**仪表盘**」→ 点右边的 **+** → 起名「佣金月报」。
2. 点页面上方「**+ 添加组件**」，加这 4 个组件（都在同一张仪表盘上）：

| 组件 | 类型 | 配置 |
| --- | --- | --- |
| 本月应付合计 | **指标卡** | 数据源 `Daily Revenue Board`；统计字段 `本笔佣金`（求和） |
| 各渠道应付 | **柱状图** | 横轴 `渠道名称`；纵轴 `本笔佣金`（求和）；勾选「分组聚合」可按 `月份` 再分 |
| 客户明细 | **表格** | 维度 `渠道名称` + `客户名称`；指标 `本笔佣金`（求和） |
| 月份切换 | **切片器** | 基于 `月份` 字段，筛所有数据源 |

3. （可选）再加一个表格组件做渠道级对账：维度 `渠道名称`，指标 `总收入(opt+现货+合约)`、
   `分佣比例`、`本笔佣金`。

## 用的时候

在「月份」切片器里选 **2026-07**，三个组件同时跟着变：总额 → 各渠道 → 客户级明细。
要「7 月 R003 是哪些客户带来的」，在客户明细里按渠道筛一下即可。

## 三个必须知道的口径

**① 看板合计是「毛佣金」，不等于月度应付。** 看板那一列是逐行
`总收入 × 分佣比例`（如实记录，退款行是负数）。月度保底 `max(0, 合计)` 是业务规则，
只体现在 `reconcile` 写出的 `Commission Summary` 表里。某个渠道当月合计为负时，
两边数字会不一样（看板是负的，应付是 0）—— 这是对的，不是 bug。

**② 「月份」列按平台时区算，不是按 `.env` 里的 BUSINESS_TIMEZONE。** 实测平台公式走
UTC+8，而业务时区默认也是 `Asia/Singapore`（UTC+8），所以两者一致。
**业务时区换成 UTC+8 以外的时区时，这一列会错月** —— `sync_base.py --apply` 的自检会拿
业务时区逐行比对并报警。2026-09-18 核对过：1,628 行按月统计与导入时的分布逐月一致，
31 个「1 号」的行月份全对。

**③ 没登记渠道的行不在统计里。** 看板上没挂上「客户」关联的行（用户没登记成渠道客户），
渠道列和本笔佣金都是空的，所以也不会进任何组件。当前 1,628 行里 341 行有归属（43 个用户），
其余 255 个用户没登记。

## 顺手做的一件事：看板按日期从近到远排

**排序不能用接口设置**（2026-09-18 实测：`sort_info` 三种写法发过去都回 `code=0`，但读回来
`property` 是空的 —— 服务端收下就扔了）。所以在界面上点一次：

`Daily Revenue Board` → 视图工具栏的「**排序**」→ 选「**交易日期**」→ 选「**降序**」。
这个排序会跟着视图保存，所有人打开都是近的在前。

（接口**能**设的是「筛选」和「隐藏列」；「分组」只能在界面点。要建视图存这套配置的话，
用 `PATCH .../views/:view_id`，筛选的 `value` 必须是一个 JSON 字符串，例如
`{"field_id":"fldX","operator":"is","value":"[\"2026-07\"]","field_type":1}`。）
